# arXiv 每日精选 · Daily Digest

每天从 arXiv 的新稿里，只挑出**能改变判断**的那几篇——不是"看起来重要"，而是"读完你会换一个做法或换一个判据"。每篇配一份可执行的笔记，每天配一份速览。

- **覆盖**：2026-10-23 → 2026-11-20，**29 天 / 90 篇**
- **宁缺毋滥**：一天 0 篇也是合法结果；综述、benchmark 报告、数据集发布、workshop 短文一律不收
- **每篇都回答同一个问题**：这篇东西，对我们手上的研究到底能借什么

## 三个入口

| 入口 | 用途 |
|------|------|
| [INDEX.md](INDEX.md) | 全量索引，按天分组，一天一行主题 + 每篇一句话 |
| [`<日期>/00_速览.md`](2026-11-20/00_速览.md) | 当天的速览：表格对比、作者核查、今日最值得看的一篇、今天的一条暗线、弃稿理由 |
| [`<日期>/NN_标题.md`](2026-11-20/01_模型知道但后训练教会了它读错.md) | 单篇笔记，固定的八个小节（〇～七） |

单篇笔记的固定结构（为什么是这个顺序）：

1. **人话版** —— 输入 / 输出 / 任务 / 老问题 / 它改了什么 / 凭什么更好 / 代价 / 类比，先读这一节就够
2. **它在跟什么较劲** —— 它要拆掉的默认假设
3. **核心思想（机制层）** —— 定理与杠杆点，不是摘要
4. **为什么反直觉 / 优雅在哪** —— 以及它的可证伪判据
5. **关键证据** —— 数字，不是形容词
6. **边界与可疑处** —— 哪一步我没核对、哪里可能不成立
7. **对我们有什么用** —— 可直接借的做法 / 判据 / 思想 / 值得做的小实验
8. **值得抄的一句话** —— 原文 + 中译

## 关于 PDF

仓库**只收录 Markdown**（全部笔记不到 1 MB），不收录论文 PDF（90 篇合计约 230 MB，且 arXiv 上本就有原文件）。

每篇笔记开头都写着 arXiv 号，直接拼 `https://arxiv.org/abs/<id>` 即可打开原文；`_meta.json` 里也有完整的 id、标题、作者与提交时间。

## 这套东西怎么产出的

抓 arXiv 新稿 → 按判据初筛 → 读全文 → 逐篇写笔记 → 写当天速览与索引。索引与速览由脚本维护，笔记正文逐篇手写，**不接受"摘要改写"充当笔记**。

## 增量更新
