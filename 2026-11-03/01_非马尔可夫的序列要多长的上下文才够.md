# 2026-10-29 · 非马尔可夫的序列,要多长的上下文才够|When Can Optimally Trained Transformers Achieve Near-Lossless Token Prediction for non-Markovian Data?

> arXiv:2610.41038 · 提交:2026-10-29 · Kağan Akman, Jake Feldman Starosta, Naci Saldi, Serdar Yüksel(Bilkent / Queen's University)
> 一句话:对非马尔可夫序列,Transformer 的误差由"有限记忆近似"决定;N 阶隐马尔可夫源的误差按 α^{⌊M/N⌋} 衰减,而实现它需要**深度 ≈ 窗口长度**。

## 〇、人话版(先看这个)

- **输入**:一个**非马尔可夫**的离散序列 $Y_0,Y_1,\dots$(取值在有限/可数集合),只给前 $M$ 个 token 作为上下文。
- **输出**:下一个 token 的预测分布。
- **任务**:**理论**(随机最优控制 + 滤波),不是新模型。
- **老问题**:"Transformer 为什么在非马尔可夫数据上也work"缺少数学解释;实践只知道"上下文越长越好",但**多长才够**、**为什么够**,没有答案。
- **它改了什么**:把"预测下一个 token"写成**部分观测随机控制**里的滤波问题:
  - 对一般的平稳遍历源,误差由"有限记忆近似误差" $\mathcal F(M,q^s)$ 控制(可以理解为**熵差**);
  - 对 $N$ 阶隐马尔可夫源,误差按 $\alpha^{\lfloor M/N\rfloor}$ **指数衰减**,$\alpha$ 由滤波稳定性(以及转移核/观测核的 Dobrushin 系数)决定;
  - 并且**显式构造**了一个深度 $M+1$、每层一个头的 Transformer 来实现截断滤波;再用最优控制训练它。
- **凭什么更好**:不是"效果更好",而是**给了"上下文长度—深度—误差"三者的定量关系**。最反直觉的一条:**深度大致要跟窗口长度同阶**——因为每多一个 token 的记忆,就多需要一层来"推进一次滤波更新"。
- **代价**:强假设(平稳遍历 / 有限阶隐马尔可夫、滤波稳定、量化观测);构造是存在性的,不是训练配方。
- **类比**:追一部连载剧。如果剧情是马尔可夫的(下一集只看上一集),你只需要记住上一集;如果是非马尔可夫的(伏笔埋了十集),你需要**记得足够长**——而"记得长"不只是把窗口拉长,还需要**更多层来消化**这些记忆。

**作者核查**:Serdar Yüksel(Queen's University,随机控制/部分观测 Markov 过程)、Naci Saldi(Bilkent),方向对口且资深。可信度:**高**(纯理论,长文)。

## 一、它在跟什么较劲

语言模型和时序预测的现实是:数据几乎都不是马尔可夫的。下一 token 依赖的不只是上一个 token,而是很长的一段历史。

实践的做法是**把窗口拉长**。但没有理论回答:

1. 多长的窗口才"够"?
2. 窗口长度和模型深度是什么关系?
3. 为什么 Transformer 这种架构能实现"从长窗口里提取足够统计量"?

## 二、核心思想(机制层)

### 1. 把"预测下一 token"变成"滤波"

如果真实数据来自一个隐马尔可夫过程(有隐藏状态 $X_r$,观测 $Y_r$),那么最优预测器就是**滤波器**:维护"给定观测历史,隐藏状态的后验"。

只给长度 $M$ 的窗口,等价于**用一个错误的先验初始化滤波器,然后只更新 $M$ 步**。于是预测误差就变成了**滤波稳定性**问题:初始化的错误,会不会被 $M$ 步观测"洗掉"?

- 如果滤波器稳定(观测信息强),误差随 $M$ **指数衰减**;
- 衰减率由 Dobrushin 系数决定——这正对应"这个序列有多容易被历史确定"。

### 2. N 阶马尔可夫:误差按 α^{⌊M/N⌋} 衰减

对 $N$ 阶源(下一状态依赖前 $N$ 个状态),"洗掉"一次需要 $N$ 个观测,所以衰减率指数是 $\lfloor M/N\rfloor$。

**读法**:记忆阶数 $N$ 越大,需要多 $N$ 倍的窗口才能达到同样的误差。这给"长上下文为什么有用"一个精确的形式。

### 3. 深度 ≈ 窗口长度

他们构造的 Transformer:**深度 $M+1$,每层一个头**。

为什么:每多一个 token 的记忆,滤波更新就要多推进一步;一层注意力只能做一次"读取 + 更新"。所以**深度大致与需要整合的窗口长度同阶**。

这是一个很硬的架构预测:如果序列的非马尔可夫阶数高,光加宽没用,得加**深**。

## 三、为什么反直觉 / 优雅在哪

- **反直觉**:上下文长度不是"免费的超参"——它和**深度**绑定。把窗口从 512 拉到 4096,理论上需要更多层,而不只是更长的输入。
- **更反直觉**:误差衰减率由**滤波稳定性**决定,而滤波稳定性是源的性质,不是模型的性质。也就是说,**有些序列天生就"记不住"**,再大的模型也无法从有限窗口恢复。
- **优雅**:没有新架构。把已有的 Transformer 放进部分观测控制框架,定理自然出现。
- **判据**:如果在某个非马尔可夫源上,窗口 $M$ 增大而误差不按 $\alpha^{\lfloor M/N\rfloor}$ 衰减,理论就不适用(或假设被违反)。

## 四、关键证据

- **Theorem 5.1**(平稳遍历源):误差 → 0,只要按顺序让量化级数、样本量、近似精度、窗口 $M$ 依次增大。
- **Theorem 5.2**($N$ 阶隐马尔可夫):以 $1-\delta$ 概率,误差按 $\alpha^{\lfloor M/N\rfloor}$ 衰减。
- **构造**:深度 $M+1$、每层一头的 Transformer 实现截断滤波;用随机最优控制训练后接近最优。
- **数值**:论文附有模拟验证。

## 五、边界与可疑处

- 假设强:平稳遍历或有限阶隐马尔可夫、滤波稳定、量化观测。
- 构造是存在性的:深度 $M+1$ 在实际中不可能(窗口 4096 就要 4097 层);理论说明的是**趋势**,不是实现方案。
- 只处理离散 token;连续值时序需要额外的量化/近似步骤。
- 我未核对全部证明。

## 六、对我们有什么用

- **可直接借(直觉)**:金融/时序是非马尔可夫的,所以"窗口长度"和"深度"要一起考虑。**只加窗口不加深度,可能只是把更多信息塞给一个消化不了的模型。**
- **可直接借(诊断)**:估一下我们数据的"有效记忆阶数" $N$(比如用偏自相关、或训练不同窗口的模型看误差何时饱和)。如果 $N$ 很大,说明需要更深/更长的上下文,而不是更宽。
- **可直接借(写作)**:审稿人问"为什么用这么长的 lookback",可以引这篇:误差按 $\alpha^{\lfloor M/N\rfloor}$ 衰减,$N$ 是数据的记忆阶数。
- **只能当反面教材**:别把"上下文越长越好"当成无条件结论——当滤波不稳定时,更长的窗口几乎不改善误差。

## 七、值得抄的一句话

> "For $N$th order Markovian sources, the error decays at an exponential rate $\alpha^{\lfloor M/N\rfloor}$."

> 对 $N$ 阶马尔可夫源,误差按 $\alpha^{\lfloor M/N\rfloor}$ 的指数速率衰减。
