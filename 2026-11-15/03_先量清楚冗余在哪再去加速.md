# 2026-11-13 · 先量清楚冗余在哪,再去加速|DRAMA: Dissecting Attention Redundancy for Accelerating Multimodal Diffusion LLMs

> arXiv:2611.16345 · 提交:2026-11-13 · Yi-Hsin Hung, Fangfu Liu, Shao-Yuan Lo, Chu-Song Chen(台湾大学 / 中研院 / 清华)
> 一句话:多模态扩散 LLM 的注意力冗余不是猜的;沿空间/时间轴量出来两条稳定结构,据此做剪枝与自适应停止,免训练拿到 18.67× 加速。

## 〇、人话版(先看这个)

- **输入**:多模态扩散语言模型(dLLM):图像 token + 文本 token 拼成一条长序列,用**双向注意力**迭代式去噪生成。
- **输出**:生成的文本;以及每一步的**注意力张量**(用于分析冗余)。
- **任务**:**推理加速**,不是新模型。
- **老问题**:dLLM 每一步都要对整条长序列做一次前向,而**视觉 token 占了大头**;再加上固定的去噪步数,成本是"步数 × 序列长度的平方"。现有加速方法多是**从零散的注意力可视化**里"看出来"冗余在哪,而不是**测出来**。
- **它改了什么**:沿**空间轴**与**时间轴**系统探测注意力张量,发现两条稳定结构:
  1. **注意力质量持续集中在少数视觉 token 上**(空间冗余);
  2. **注意力分布在初始形成阶段后迅速稳定**(时间冗余)。
  据此设计两个机制:
  - **SVTP**:空间冗余感知的视觉 token 剪枝;
  - **SGAS**:充分性引导的自适应停止(不必跑满所有去噪步)。
- **凭什么更好**:六个视觉语言基准上平均 **18.67× 加速**,**无需训练、不改架构、不做注意力缓存**,精度保持竞争力。
- **代价**:依赖"冗余结构确实稳定"这一经验事实;不同模型/任务可能不同;剪枝策略需要按模型校准。
- **类比**:一场会议里,发言的其实只有几个人,其余人重复点头。先**数一数**谁在说话(空间冗余),再看**什么时候讨论已经定型**(时间冗余),就能把会议缩短到几十分之一,而结论不变。

**作者核查**:Chu-Song Chen(台湾大学/中研院,计算机视觉资深)、Fangfu Liu(清华),有开源代码。可信度:**较高**(preprint,基准完整)。

## 一、它在跟什么较劲

dLLM(扩散式语言模型)的推理成本结构:

- 每个去噪步:一次全序列前向 → $O(L^2)$;
- 视觉 token 让 $L$ 变得很大;
- 步数是固定的。

于是加速有两个天然方向:**少看一些 token**(空间)、**少走几步**(时间)。

但"哪些 token 可以少看""哪一步可以停",过去多靠**观察几张注意力热图**拍脑袋。

## 二、核心思想(机制层)

### 1. 空间冗余:注意力质量集中在少数视觉 token

量出来的事实:大部分注意力质量落在**稀疏的一小部分**视觉 token 上,其余 token 贡献很小。

于是可以**剪掉低质量 token**,而不显著改变输出。

### 2. 时间冗余:分布很快稳定

量出来的事实:去噪开始有一个"形成阶段",之后注意力分布**迅速稳定**。

既然分布不再变化,继续跑步数的**边际信息**很小 → 可以**自适应停止**。

### 3. 两个机制合起来

- SVTP 降低每步成本($L$ 变小);
- SGAS 降低步数($T$ 变小);
- 两者相乘,得到 18.67× 的平均加速。

关键是:**这是"测量驱动"的设计**,不是"先设计再解释"。

## 三、为什么反直觉 / 优雅在哪

- **反直觉**:扩散模型的"迭代去噪"看起来每一步都在提供新信息,但**注意力分布早就定型了**——信息在变,路由没变。
- **更反直觉**:不做 KV 缓存、不改架构、不重训,也能拿到近 20 倍加速。
- **优雅**:两条冗余结构,对应两个正交的加速轴(空间/时间),乘起来。
- **判据**:如果剪掉的 token 或跳过的步数导致精度显著下降,说明冗余结构不成立(他们的实验是"精度保持竞争力")。

## 四、关键证据

- 注意力张量的空间/时间探测:两条冗余结构;
- SVTP + SGAS:六个基准平均 **18.67×** 加速;
- 无训练、无架构改动、无注意力缓存;
- 精度保持竞争力;
- 代码开源。

## 五、边界与可疑处

- 冗余结构是经验观察,不保证对所有 dLLM/任务成立。
- "精度保持竞争力"需要看具体任务的最坏情况。
- 剪枝阈值与停止准则需要校准。
- 我未核对全部基准数字。

## 六、对我们有什么用

- **可直接借(方法)**:**先量冗余,再设计加速。** 我们的模型(多分支、多尺度、多步去噪)同样可以先量"注意力/计算质量集中在哪",再决定剪哪里、停在哪。
- **可直接借(判据)**:**"路由是否已经定型"** 是一个比"损失是否还在降"更细的停止信号。如果注意力分布已稳定,继续算的边际价值可能很低。
- **可直接借(思想)**:**空间冗余与时间冗余是两个正交的轴**,可以分别优化再相乘。我们的推理成本也可以按"看多少输入 × 走多少步"分解。
- **值得做的小实验**:在我们模型的每个去噪/迭代步,记录注意力(或路由)分布的熵;画熵随步数的曲线,找到"定型点",在那之后尝试提前停止。

## 七、值得抄的一句话

> "Existing inference acceleration approaches ... characterize attention redundancy implicitly, motivating designs from isolated attention visualizations rather than from measurement."

> 现有的推理加速方法隐式地刻画注意力冗余,其设计动机来自零散的注意力可视化,而不是来自测量。
