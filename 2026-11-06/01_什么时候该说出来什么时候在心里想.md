# 2026-11-04 · 什么时候该"说出来",什么时候在心里想|Learning When to Think Aloud in Latent Reasoning

> arXiv:2611.06108 · 提交:2026-11-04 · Zhehao Zhou, Tongrui Su, Shengyu Zhu, Da Li, Zeyu Liu, Jun Zhu, Xueqi Cheng(北理工 / 中科院计算所 / 快手)
> 一句话:全隐式推理省 token 但在精确任务上掉点;全显式太贵。真正的解法是**让模型自己决定哪几个 token 值得说出来**。

## 〇、人话版(先看这个)

- **输入**:一道题 + 一条参考的显式 CoT;以及一个语言模型。
- **输出**:一条**混合轨迹**——大部分步骤是隐状态推进(不产生 token),少数关键位置吐出显式 token 作为"推理锚点"。
- **任务**:**隐空间/混合 CoT 推理**,不是新架构。
- **老问题**:全隐式(latent)方法省 token,但在数学这种**精确计算**任务上经常掉点;混合方法(把部分 CoT 显式化)又保留了大量 token 开销——比如有些方法每一步仍然要吐一个 token。
- **它改了什么**:
  1. 用**token 重要性估计**从显式 CoT 里挑出少数"信息量大"的 token,作为锚点;
  2. 加一个**轻量门控头**,动态决定这一步是"吐 token"还是"直接隐状态回灌";
  3. 训练分两段:课程式监督(先学模仿混合轨迹)+ RL(奖励同时看**正确性**与**简洁性**)。
- **凭什么更好**:在可比推理长度下,相对全隐式方法平均提升 **+9.6%(GPT-2)**、**+5.1%(Llama-3.2-1B)**;与混合基线相比,在 Qwen3-1.7B 上**更准且轨迹更短**。
- **代价**:需要一个"重要性估计"来构造训练轨迹;两段式训练(课程 + RL);只在数学/推理任务上验证。
- **类比**:做心算。全隐式 = 全程不写草稿,心算复杂题容易错;全显式 = 每一步都写下来,慢。高手是:**只在关键的中间结果上写一笔**(比如进位、余数),其余在心里推。

**作者核查**:Jun Zhu(清华教授,贝叶斯深度学习,Google Scholar 高引)、Xueqi Cheng(中科院计算所)、Shengyu Zhu(中科院计算所),一作来自北理工。可信度:**较高**(preprint,作者阵容强)。

## 一、它在跟什么较劲

隐空间推理的取舍很清楚:

- **全隐式**:每个中间步骤只是一个连续向量,零 token 成本;但**离散、精确的中间量**(比如算到 7×8=56)在连续状态里容易被"糊掉";
- **全显式**:准确,但 token 贵,而且很多 token 是语言连贯性的废话;
- **现有混合**:把开头一段 CoT 显式化,或者每步仍吐一个 token——前者不够灵活,后者没省多少。

问题是:**哪些中间结果必须被"钉"成离散符号,哪些可以留在连续空间?**

## 二、核心思想(机制层)

### 1. 用重要性挑锚点

对参考 CoT 的每个 token 估计"它对最终答案的影响"。挑出高重要性的少数 token 作为锚点。

这些锚点通常是:**数字、中间计算结果、关键实体**——也就是"一旦糊掉就会错"的东西。

### 2. 门控头:动态决定说还是想

一个轻量门控头在每一步判断:输出显式 token,还是直接把隐状态回灌作为下一步输入。

于是模型可以:

- 在需要精确的地方"说出来"(离散化,防糊);
- 在需要大量计算但不需要精确中间量的地方"心里想"(省 token)。

### 3. 训练:先模仿,再优化"又对又短"

- **课程式监督**:从显式 CoT 构造混合轨迹,让模型学会"在该说的地方说";
- **RL**:奖励 = 正确性 + 简洁性。这很关键——只奖励正确,模型会退化成全显式;只奖励简洁,会退化成全隐式。

## 三、为什么反直觉 / 优雅在哪

- **反直觉**:隐空间推理的瓶颈不是"容量",而是**离散性**。连续状态适合"算",不适合"记精确符号"。
- **更反直觉**:最好的策略不是"全隐"或"全显",而是**稀疏的显式锚点**——用最少的 token 买回精确性。
- **优雅**:门控头很小,不改主干;锚点由重要性决定,可解释。
- **判据**:如果把锚点换成随机位置,性能应显著下降。这是它的消融。

## 四、关键证据

- **vs 全隐式**:GPT-2 上相对平均 **+9.6%**,Llama-3.2-1B 上 **+5.1%**,推理长度可比。
- **vs 混合基线**:Qwen3-1.7B 上更高准确率 + 更短轨迹。
- **消融**:去掉重要性选择(随机锚点)、去掉门控(固定模式)、去掉 RL 的简洁项,各自变差。
- **可解释**:锚点集中在数字与中间结果上,符合"精确量需要离散化"的直觉。

## 五、边界与可疑处

- 只在数学/逻辑推理上验证;开放式推理的"重要性"定义模糊。
- 重要性估计本身需要额外计算/标注。
- 两段式训练,RL 奖励权重(正确 vs 简洁)是敏感超参。
- 我未核对全部实验与实现细节。

## 六、对我们有什么用

- **可直接借(核心思想)**:**连续隐状态负责"算",离散 token 负责"记精确量"。** 我们的 K 分支/隐空间 CoT 如果涉及精确数值(价格、阈值、分位数),应该保留少量"锚点"把它们钉住,而不是全交给连续状态。
- **可直接借(做法)**:门控头 = 一个很小的分类器,决定"这一步要不要产出可读符号"。实现成本低。
- **可直接借(训练)**:奖励里必须同时有"对"和"短",否则会退化成两个极端。
- **值得做的小实验**:在我们的隐空间推理里,把关键数值(如预测的分位数)显式输出为 token,其余保持隐式,看 CRPS 与延迟的 trade-off。

## 七、值得抄的一句话

> "Selectively verbalizes informative tokens as reasoning anchors while keeping most computation latent."

> 选择性地把有信息量的 token 说出来作为推理锚点,同时让大部分计算留在隐空间。
