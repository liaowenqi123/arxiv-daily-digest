# 2026-11-10 · 循环预测模型一直没用它的"初始状态"|The Unused Input: The Initial State as a Conditioning Interface for Recurrent TSFMs

> arXiv:2611.14357 · 提交:2026-11-10 · Bernhard Voggenberger, Christian Ganhör, Levente Zólyomi, Sebastian Böck, Sepp Hochreiter(NXAI / JKU Linz)· NeurIPS 2026 FMTS Workshop
> 一句话:循环时序基础模型的预测有两个输入——上下文窗口和**初始状态**;而初始状态一直被设成默认值。把它当一个条件接口用,能白拿一点性能。

## 〇、人话版(先看这个)

- **输入**:一个循环骨干的零样本预测器(TiRex,基于 xLSTM);一段上下文窗口;以及**一个初始循环状态**。
- **输出**:预测;以及"注入初始状态后"的精度变化。
- **任务**:**时序基础模型的适配接口**,不是新模型。
- **老问题**:循环模型每一步代价恒定,长上下文便宜,而且**带状态**——这是它相对 Transformer 的优势。但实践中,初始状态被设成一个固定的默认值,**不含关于被预测序列的任何信息**。也就是说:一个完整的条件通道被空着。
- **它改了什么**:**冻结骨干**,只训练一个很小的头,把一个"上下文向量"写进初始状态。这样精度变化只能归因于注入的状态,而不是权重被改了。三种注入内容:
  1. **频谱摘要**(对输入窗口做一次频谱汇总,学一次、对所有序列通用):平均 GiftEval MASE 降 **0.175%**,**每一个种子都改善**;而参数对齐的 LoRA、或可学习的静态状态,都复现不出这个效果;
  2. **静态状态**:在六个 MoTime 数据集上作为"逐数据集适配面",MASE 降 **0.04–6.96%**(相当于全量微调收益的 8–70%);
  3. **文本嵌入**(序列附带的文字说明):作为外生信息通道,再降 **0.15–0.41%**(六个数据集中的四个);与 LoRA 组合时,在一个数据集上**超过全量微调**(而全量微调看不到那段文本)。
- **机制定位**:在 TiRex 里,效果集中在 **mLSTM 块**;在**短上下文**时最强。
- **凭什么更好**:证明了这个通道**有用且可归因**——不是"改权重碰巧变好",而是"注入的信息本身带来了收益"。
- **代价**:作者自己说"结果是初步的,提升很小";只做一个模型;文本通道只在一部分数据上有效。
- **类比**:一台空调既有"遥控器"(上下文窗口),也有"开机时的默认设定"(初始状态)。大家一直只用遥控器,从不去设开机状态。这篇说:开机状态其实可以携带信息——比如"今天要除湿"。

**作者核查**:Sepp Hochreiter(JKU Linz,NXAI,LSTM 提出者)、Sebastian Böck(NXAI,通讯作者),方向对口。可信度:**较高**(NeurIPS workshop,结论谨慎标注为 preliminary)。

## 一、它在跟什么较劲

循环 TSFM 的卖点是"有状态"。

但状态在推理时**从默认值开始**,然后被上下文一步步覆盖。于是:

- 初始状态不携带任何序列信息;
- 所有"序列级"的差异,必须靠上下文窗口里的几百个点去表达;
- 模型没有一个"便宜的全局条件入口"。

对比 NLP:prompt tuning / prefix tuning 正是给冻结模型加"软条件"的手段;在 SSM 上,已有工作证明**直接调初始状态**至少和 prefix tuning 一样有表达力。

## 二、核心思想(机制层)

### 1. 状态是一个条件接口,不是实现细节

把初始状态 $h_0$ 看成"序列级条件"的载体:

$$h_0=g_\phi(\text{condition}),\qquad \hat y=f_\theta(\text{context};h_0)$$

冻结 $\theta$,只学 $g_\phi$(小头),于是 $\Delta$MASE 完全归因于 $h_0$ 携带的信息。

### 2. 三种条件,三种角色

- **频谱摘要**:与具体序列无关的"通用先验",学一次用 everywhere → 稳定的小幅提升;
- **静态状态**:每个数据集一个向量 → **逐数据集适配**,接近微调收益的一部分,但参数几乎为零;
- **文本嵌入**:把序列附带的文字(描述、元数据)编码进状态 → **外生信息通道**。

第三种最有意思:它给了模型一种"看到数据之外信息"的方式,而**全量微调反而做不到**(权重里没有这段文本)。

### 3. 效果集中在哪里

- 集中在 **mLSTM 块**(而不是 sLSTM 或输出头);
- **短上下文时最强**——因为上下文短时,模型能自己提取的信息少,初始状态的信息更值钱。

这正好符合"条件接口"的解释。

## 三、为什么反直觉 / 优雅在哪

- **反直觉**:一个"显然该被利用"的输入,被整个领域按惯例空着。
- **更反直觉**:提升虽小(0.175%),但**每个种子都改善**,而参数对齐的 LoRA 做不到——说明这不是"多了点容量",而是"多了一条信息通道"。
- **优雅**:冻结骨干 + 小头,把因果归因做干净了。
- **判据**:如果可学习的静态状态也能达到同样效果,那"频谱摘要携带信息"的解释就弱了(他们的实验恰好相反)。

## 四、关键证据

- 频谱摘要:mean GiftEval MASE **−0.175%**,全种子改善;LoRA 与可学习静态状态均未复现;
- 静态状态:六个数据集 **−0.04%~−6.96%**,达全量微调收益的 8–70%;
- 文本条件:四个数据集再降 **0.15–0.41%**;与 LoRA 组合在一个数据集上超过全量微调;
- 定位:mLSTM 块、短上下文最明显;
- 作者明确标注 preliminary。

## 五、边界与可疑处

- 提升很小(千分之几),实际部署是否值得,要看成本。
- 只测 TiRex 一个骨干;Mamba/DeltaNet 类模型未验证。
- 文本条件依赖"每个序列有可用文本",很多场景没有。
- workshop 论文,实验规模有限。
- 我未核对全部表格。

## 六、对我们有什么用

- **可直接借(接口)**:我们的循环/状态空间模型,初始状态也不该是常数。它可以承载**序列级条件**:资产 ID、频率、regime 标签、宏观状态、甚至文本(新闻/公告)。
- **可直接借(做法)**:冻结骨干 + 小头写 $h_0$,先验证"这条通道值不值钱",再决定要不要端到端训。这是一种很便宜的消融。
- **可直接借(细节)**:短上下文时收益最大——如果我们的推理窗口很短(高频),这条通道可能比想象中重要。
- **值得做的小实验**:固定骨干,只学一个把 regime one-hot 映射到 $h_0$ 的线性层,看多步预测的 CRPS 是否改善。

## 七、值得抄的一句话

> "In practice only the first is utilised and the initial state is unused by convention."

> 实践中只用了第一个输入(上下文窗口),而初始状态按惯例被闲置着。
