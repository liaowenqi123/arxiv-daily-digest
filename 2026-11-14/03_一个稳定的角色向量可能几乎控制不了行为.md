# 2026-11-11 · 一个稳定的"角色向量",可能几乎控制不了行为|What Roles Do System Prompts Really Assign? Validating and Steering Occupational Role Vectors in LLMs

> arXiv:2611.15989 · 提交:2026-11-11 · Jose L. Sampedro Mazon, Ilmi Yoon, Nadim Saad(San Francisco State University 等)
> 一句话:角色向量可以"稳定、可分、跨域一致",却仍然**几乎不能操控**模型行为——可读出与可控制是两件事。

## 〇、人话版(先看这个)

- **输入**:system prompt 里的一句话,例如"你是一位资深税务会计师";两个指令模型(Qwen2.5-7B-Instruct、Llama-3.1-8B-Instruct)。
- **输出**:每个职业对应的**角色向量**(激活层面上的一个方向),以及注入它之后的行为变化。
- **任务**:**表征与控制的验证框架**,不是新方法。
- **老问题**:从业者用 system prompt 给模型"设定角色",但没人检验:这个角色在**激活层面**上是不是一个稳定、可分的表示?如果稳定,能不能**直接注入**来控制行为?已有工作主要看"效果"(能预测/能操控就算有效),没有先问"它到底是不是一个可靠的表示"。
- **它改了什么**:用**两把尺子**同时量:
  1. **可解释性之尺**:向量是否**可复现**(重复运行、不同采样温度)、**可分**(即使角色很相似)、**跨域一致**(在领域内与领域外问题上,更像自己而不是别的角色);
  2. **控制之尺**:把这个向量注入生成过程,能不能让模型**表达**该角色、并在**多轮对话**中**维持**它,达到"用 prompt"的水平。
- **发现(关键)**:
  - 在 Qwen 上,单独注入向量确实让模型更常表达目标角色,但**最好也只是追平 prompt**;
  - 在两个模型上,把向量**加到 prompt 上**能增强单次回答里的角色感,但**并没有减缓角色在 30 轮对话中的衰减**;
  - 领域外,角色表达很微弱,**但激活里仍然编码着它**。
- **凭什么更好**:它把"表示"和"控制"分开检验,并给出反例:**一个通过所有表示检验的向量,可能几乎控制不了行为**。
- **代价**:只有两个模型;职业角色这一类概念;注入方式有限(加向量/加 prompt)。
- **类比**:你从体温计上读出了"发烧"(表示可靠),但你并不能靠**把体温计泡进热水**来给病人退烧(控制)。读出与控制,是两套机制。

**作者核查**:Ilmi Yoon(San Francisco State University,计算机科学,主页可查)、Jose L. Sampedro Mazon、Nadim Saad。可信度:**较高**(preprint,双向验证设计)。

## 一、它在跟什么较劲

"角色向量""人格方向""概念方向"这类工作,通常用**效果**来证明有效性:

> 这个方向能预测行为 / 注入后行为改变 ⇒ 它是有效的表示。

但这个推理有两个漏洞:

1. **能预测 ≠ 是可靠表示**:可能换种子就变、可能和邻近概念混在一起;
2. **能描述 ≠ 能控制**:即使是一个稳定表示,注入它也可能推不动行为,因为行为由**下游计算**决定,而不只由这个方向决定。

## 二、核心思想(机制层)

### 1. 两把尺子,缺一不可

- **可解释性之尺**:可复现性、可分性、跨域一致性;
- **控制之尺**:注入后是否表达、是否在多轮中维持、能否追平 prompt。

**关键**:这两把尺子测的是不同的东西。通过第一把,不保证第二把。

### 2. 提取:用对比的方式找"角色方向"

用同一批任务,分别以不同角色 prompt 生成,取激活差的平均方向——标准做法。

### 3. 结果:表示很稳,控制很弱

- 向量本身高度可复现、可分、跨域一致;
- 但注入的**行为效应有限**:单独注入最多追平 prompt;加到 prompt 上只增强单次回答,**不减缓 30 轮衰减**。

**读法**:角色在激活里"在那儿",但它不是行为的**充分控制变量**。

### 4. 领域外:表达弱,编码仍在

领域外问题上,模型不怎么表现出角色,但激活仍编码角色。

这说明:**"没表现出来"不等于"没有表示"**——反过来也提醒我们:探针能读出,不代表模型在用。

## 三、为什么反直觉 / 优雅在哪

- **反直觉**:一个"教科书级干净"的方向,注入后几乎推不动行为。
- **更反直觉**:加向量到 prompt **不能**减缓多轮衰减——衰减不是"角色信号不够强",而是别的东西(上下文累积、注意力转移)在起作用。
- **优雅**:不需要新方法,只需要**两把尺子一起量**,反例就出来了。
- **判据**:如果某个方向既能稳定提取、又能显著操控且能维持多轮,那"表示≠控制"的结论就被推翻(至少对这个方向)。

## 四、关键证据

- **可复现**:跨运行、跨采样温度高度一致;
- **可分**:相似角色也能分开;
- **跨域一致**:领域内外都更像自己;
- **控制有限**:Qwen 上单独注入最多追平 prompt;两模型上向量+prompt 不减缓 30 轮衰减;
- **领域外**:行为弱但激活仍编码。

## 五、边界与可疑处

- 只两个模型;职业角色一类;注入方式有限。
- "角色表达"的判定依赖评分方式(可能是 LLM 打分)。
- 30 轮衰减可能受对话长度/上下文影响,不完全是角色信号问题。
- 我未核对全部实验细节。

## 六、对我们有什么用

这条和我们反复遇到的"知道 ≠ 会用"是同一条线,而且给了一个**可操作的检查表**:

- **可直接借(检查表)**:任何"我们找到了 X 的方向/因子"的主张,都要过两把尺子:① 它稳定、可分、可复现吗?② 改动它,行为真的变吗?**只过第一把,不能声称"机制"**。
- **可直接借(诊断)**:如果探针能读出 regime,但按 regime 调整策略没有改善,那说明 regime 表示不是**控制变量**——还需要找到真正驱动行为的那条通路。
- **可直接借(警告)**:"加一个条件向量到输入"未必能改变多步行为;多轮/多步的衰减往往来自累积效应,不是单点信号强度。
- **值得做的小实验**:在我们的模型里,提取"高波动 regime 方向",注入后用**多步**预测看是否维持——很可能单步有变化,多步就衰减了。

## 七、值得抄的一句话

> "A vector that is stable and separable can still barely steer the model's behavior."

> 一个稳定且可分的向量,仍然可能几乎无法操控模型的行为。
