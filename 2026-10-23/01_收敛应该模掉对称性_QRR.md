# 2026-10-13 · 收敛不必发生在原始空间|Looped Reasoning Finishes Earlier Than You Think

> arXiv:2610.18174 · 提交:2026-10-13 · Sumin Park, T. Konstantin Rusch(ELLIS Tübingen / MPI-IS / Liquid AI)
> 一句话:把"收敛"从原始隐状态改成"模掉一个精确对称群之后的商空间",慢振荡就不再拖累推理。

## 〇、人话版(先看这个)

- **输入**:一道题。Sudoku 是 81 个格子的题面(每格 1–9 或空);迷宫是一张 30×30 的地图;Mini-ARC 是 5×5 的彩色网格。
- **输出**:答案。每格填什么数字 / 从起点到终点的路径 / 变换后的网格。
- **任务**:**迭代求解**,不是预测、不是分类。模型把题编码成一串向量,再让同一组权重反复"想"几十到几千轮,最后读出答案。
- **老问题**:循环推理靠"状态不再变化"判断"想完了"。但状态会一直小幅摆动,于是 ① 机器迟迟不停,白算很多轮;② 有人加阻尼强行压平,结果把有用的计算也压掉了。
- **它改了什么**:给每个 token 加一个"整体旋转角度"的自由度,并规定**这个旋转不算变化**。判断"想完了"只看扣掉旋转后剩下的部分。旋转还在转,但系统认为已经收敛。
- **凭什么更好**:Sudoku 准确率 97.9%(原 91.5%);到达答案的中位步数 122(原 234);整体耗时 5.4s → 1.9s。
- **代价**:单步计算贵约 1.5 倍、显存多 30%;只在三个小规模推理任务上验证。
- **类比**:判断洗衣机停稳。老传感器测"桶在不在动",桶一直轻微晃就永远不停;新方法只测"衣服相对桶有没有变",晃动不算运动。

**作者核查**:T. Konstantin Rusch 长期做神经 ODE 与循环网络,现挂 ELLIS Tübingen 与 Liquid AI——方向对口、有连续产出,**但不是资深大牛**;一作 Sumin Park 是学生。可信度:中上,结论建议自己复现后再引。

## 一、它在跟什么较劲

循环推理(looped reasoning)现在的主流叙事是:**推理 = 隐状态向某个解吸引子松弛**。FPRM 直接拿"到达不动点"当停机判据,EqR 学任务条件吸引子。

但真实轨迹不老实:会交替、绕圈、漂移。领域内的默认反应有两种——
1. 当它是"还没收敛",于是加步数、加算力;
2. 当它是"数值不稳",于是加阻尼(FPRM 就带一个 step-size controller)。

作者指出这是一个**两难**:慢衰减的振荡模态会把自身收敛速率"传染"给与它耦合的其余维度,成为瓶颈(Theorem 3.2:$\tau_\delta = \log(1/\delta)/(-\log r)+O(1)$,瓶颈速率就是那个 $r$);可是**直接压掉振荡又会破坏推理**——附录 A.4.4 里,在语义稳定之前压掉 FPRM 的交替模态,任务性能下降。

所以问题不是"怎么把振荡消掉",而是:**凭什么把这段运动算作"还没算完"?**

## 二、核心思想(机制层)

一句话:**不改动力学,改"什么算运动"。**

做法是给每个 token 一个 $U(1)$ 相位自由度(复化表示,实部虚部成对),要求:

- recurrent map $T$ 对这个相位**等变**:$T(g\cdot z)=g\cdot T(z)$;
- readout $R$ 对它**不变**:$R(g\cdot z)=R(z)$。

于是相位方向上的运动在商空间 $Z/G$ 里是恒等映射。关键不是"忽略",而是"解耦":在相对平衡点 $T(z^\star)=g^\star z^\star$ 处,商空间版的耦合矩阵 $B_G=0$——**对称方向的运动在构造上就无法把时间尺度传给商动力学**(Prop A.2)。慢模态还在,但它已经不是瓶颈了。

停机判据也随之改写:

$$r_G(z)=\inf_{g\in G}\frac{\|T(z)-g\cdot z\|}{\|z\|+\epsilon}$$

即"我和我的下一步,是否只差一个规范变换"。

**如果只能记住一张图**:FPRM 的轨迹是绕圈逼近一个点;QRR 的原始轨迹仍然在转,但它的影子(商轨迹)是单调收缩的。收敛发生在影子里。

## 三、为什么反直觉 / 优雅在哪

- **反直觉**:要更快收敛,不是减少自由度,而是**增加**自由度——而且增加的是一组"按定义不可见"的自由度。通常"加对称性"是为了泛化或省参数;这里是为了**定义收敛**。
- **优雅**:没有新损失、没有控制器、没有课程学习、没有蒸馏。只是在架构里放一个精确对称,然后用群论把无意义的运动从判据里除掉。阻尼是"对抗"动力学,商化是"承认"动力学。
- **判据**:如果商空间的收敛加速不能换成端到端 wall-clock 下降(只是指标变好看),这个想法就错了。他们的回答是 rollout 中位数 5.4s → 1.9s。

## 四、关键证据

| 量 | FPRM | QRR |
|---|---|---|
| Sudoku-Extreme 准确率 | 91.51(官方)/ 83.73(复现) | **97.9** |
| 到达解根的中位步数 $\tau_{root}$ | 234 | **122** |
| 自适应停机中位步数 | 122 | **27** |
| 错误停机率 | 8.9% | **0.1%** |
| 端到端 rollout p50 / p95 | 5.4s / 168.1s | **1.9s / 60.0s** |

单次前向反而更贵(34.7ms vs 22.3ms,显存 2.88 vs 2.14GB)——**但收敛快赢了**。

消融很关键:
- 把 token-local $U(1)^S$ 退化成**单一全局 $U(1)$**:准确率还有 91.3%,但**停机判据永远不触发**(CAP)。说明残余的相位运动是逐 token 的,全局相位不够。
- 去掉 momentum(一阶动力学):87.8%,覆盖 79.6%。
- 换回 FPRM trunk + momentum:77.0%,而且 12,650 步才停。→ 不是"加了点东西",是**等变结构本身在起作用**。

## 五、边界与可疑处

- 只在 Sudoku / Maze / Mini-ARC 三个小模型任务上验证,7M 参数级别。不能直接推广到语言模型。
- QRR 是 FPRM 的改造版,不是"任意循环推理都该商化"的普适结论。
- 商空间判据的阈值仍需校准(校准方式在附录,我没逐行核)。
- 一个我没看到直接回答的问题:**模型会不会把信息塞进规范方向?** readout 对它不变,理论上那部分容量是"自由但无用"的;作者只论证了它不干扰,没论证它不被滥用。
- Sudoku 上 root-finding rate 89.6% 略低于 FPRM 的 90.4%——快是快了,解根找到率略降,论文没强调这一点。

## 六、对我们有什么用

对"K 分支隐空间推理 + Drifting 1-NFE"这条线:

**可直接借(思想,不是组件)**:K 条分支之间存在天然的**置换对称** $S_K$——第 1 条分支和第 3 条分支交换,是同一个假设集合。我们的收敛/停机判据现在是 $\|z_{t+1}-z_t\|$,它会把"分支换了个顺序"误判成"还在动"。正确的判据应是

$$\min_{\pi\in S_K}\|z_{t+1}-\pi\cdot z_t\|$$

这几乎是免费的,而且**可证伪**:如果模掉置换后停机大幅提前而精度不掉,说明我们之前的"没收敛"有一部分是标签排列在晃。

**只能当反面教材**:不要在没有**精确**对称时硬套 quotient。近似对称会漏掉真实运动,把"没算完"误判成"算完了"——这比慢更危险。

**值得做的一个小实验**:在现有 K 分支模型上,同时记录原始判据与置换商判据的停机时刻,画"提前量 vs 精度损失"曲线。一天能跑完。

## 七、值得抄的一句话

> "Convergence in recurrent reasoning is better understood in terms of task-relevant quotient space than raw latent space."

> 循环推理的收敛,应该在"任务相关的商空间"里理解,而不是在原始隐空间里理解。
